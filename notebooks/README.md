# Дополнительные эксперименты Incident Copilot

`EDA.ipynb` в корне — единый основной отчёт для чекпойнта. Здесь находятся вспомогательные исследования, которые команда может расширять независимо от сдаваемого файла.

- `01_retrieval_candidates.ipynb`: согласие топ-3 BM25 и Dense. Не является Recall@K — требуется проверенная qrels-разметка.
- `02_augmentation_experiments.ipynb`: сдвиг эмбеддингов при paraphrase/typo. Не заменяет ручную проверку сохранения смысла.
- `03_source_extension_template.ipynb`: схема подключения нового корпуса.

Все три ноутбука запускаются **из корня репозитория** после подготовки `reports/` и `data/processed`. Проверенные результаты переносятся в основной EDA, чтобы финальная сдача оставалась единым исследованием.
