# Retrieval по технической документации

[Ноутбук](documentation_qa.ipynb) сравнивает BM25, BGE, CLIP и Qwen3-VL-Embedding-2B на 352 вопросах с принятым ответом. Цель поиска — страница официального руководства, на которую ссылается автор ответа. В последнем разделе проверяется связь промахов с наличием изображения в вопросе.

| Корпус | Вопросы | Версия документации |
|---|---:|---|
| Matplotlib | 200 | [3.10.7](https://matplotlib.org/3.10.7/) |
| Blender Geometry Nodes | 106 | [4.5](https://docs.blender.org/manual/en/4.5/) |
| QGIS, растровый анализ | 46 | [3.44](https://docs.qgis.org/3.44/en/docs/) |

## Как собирали корпус

Через Stack Exchange API собрали вопросы за 2021–2025 годы со Stack Overflow (тег `matplotlib`), Blender Stack Exchange (`geometry-nodes`) и GIS Stack Exchange (`qgis` вместе с `raster`). Оставили вопросы, где принятый ответ ссылается хотя бы на одну страницу официальной документации, которую автор вопроса сам не указал. Эти страницы стали целями retrieval. Для Matplotlib взяли 100 вопросов с наибольшим рейтингом и 100 случайных из остальных (seed 42), для Blender и QGIS — все прошедшие фильтр. В выборку включали вопросы как со скриншотами, так и без них. [Скрипт отбора](scripts/collect.py)

Для каждого продукта к целевым страницам добавили до 100 случайных страниц по теме и по одной странице, наиболее похожей на заголовок каждого вопроса по символьному TF–IDF. После объединения и удаления повторов получилось 663 страницы. Их разбили по заголовкам на фрагменты до 115 слов и сохранили иллюстрации вместе с исходными URL. [Подготовка документации](scripts/prepare.py)

## Что показал мультимодальный эксперимент

Наша гипотеза — RAG-система сможет точнее отвечать на технические вопросы, если свяжет деталь на скриншоте пользователя с иллюстрацией и пояснением в документации. Например, в вопросе о Blender скриншот может показывать, какие узлы соединены, а схема в руководстве — куда должен поступать конкретный параметр.

Первичный эксперимент проверял этап retrieval. Когда Qwen видел только текст и код, доля промахов в топ-5 составляла **59,5%** для вопросов с изображением и **43,9%** для вопросов без него. После учёта продукта и группы по рейтингу разница составила **12,4 п.п.** (95%-й интервал от 0,8 до 23,7 п.п.). Добавление изображений с обеих сторон с помощью Qwen3-VL-Embedding-2B не дало общего прироста. В обоих режимах целевая страница попала в топ-5 для **163 из 352 вопросов (46,3%)**. Изображения помогли в десяти случаях и ухудшили результат в десяти других. Качество итоговых ответов RAG в этом эксперименте не оценивалось.

### Следующие направления исследований

- **Скриншот в запросе.** Сравнить retrieval по полному скриншоту, по области, на которую указывает пользователь, и по тексту, извлечённому через OCR. Изменение ранга покажет, в каких случаях достаточно распознать надпись, а в каких важна пространственная связь между элементами.
- **Иллюстрация в документации.** Для выбранного шага инструкции индексировать вместе абзац, рисунок, на который он ссылается, и подпись. Проверить, помогает ли такая связь находить нужный шаг внутри страницы.
- **Мультимодальный reranking.** Получить кандидатов текстовым поиском, затем переупорядочить их с учётом скриншота запроса и иллюстраций кандидатов. На одних и тех же вопросах сравнить Hit@5 и долю ответов, которые правильно решают задачу пользователя и подтверждаются указанным фрагментом руководства.

## Просмотр и запуск

Сохранённые таблицы и графики доступны при открытии ноутбука. Для пересчёта откройте его из каталога `multimodal-documentation-qa` или корня репозитория. При `rerun_inference = False` ячейки читают локальные снимки выдачи. Для этого достаточно Python 3.12 с Jupyter, pandas, NumPy, SciPy, Matplotlib и Pillow.

Для повторения исходного окружения на macOS arm64 из каталога `multimodal-documentation-qa`:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m ipykernel install --user --name documentation-qa --display-name 'Documentation QA'
```

Выберите это ядро в Jupyter. Для полного локального inference подготовьте изображения и веса и переключите `rerun_inference` в `True`. Исходный прогон Qwen выполнялся на Metal (MPS).

```sh
.venv/bin/python -m zipfile -e data/assets.zip data/assets
.venv/bin/python scripts/weights.py
.venv/bin/python scripts/weights.py --qwen
```

## Снимок данных

- [questions.jsonl](data/questions.jsonl) — исходные вопросы и принятые ответы, ID, авторы, ссылки на публикации и целевые страницы. Условия использования материалов площадки описаны в [справке Stack Overflow](https://stackoverflow.com/help/licensing).
- Для каждого продукта `*-selection.json` содержит параметры отбора, `*-pages.json` — индекс страниц, `*-corpus.json.gz` — фрагменты, URL и соответствие изображений локальным именам, `*-structure.json.gz` — структурные признаки.
- [assets.zip](data/assets.zip) — 1 161 локальная JPEG-копия из манифестов корпусов. Для каждого файла исходный URL можно найти в `available_assets` соответствующего корпуса.
- `*-rankings.json` и `*-qwen-rankings.json` содержат топ-10 по вопросам. По ним можно повторить оценку Hit@5, Recall@5 и MRR@10 без загрузки моделей.

Код сбора, подготовки, локального inference и проверки ошибок находится в [scripts](scripts/). Повторное обращение к Stack Exchange API может дать другой состав выборки вследствие изменений рейтингов и ответов.
